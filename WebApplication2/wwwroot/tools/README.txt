FastReport Desktop tool (download)
=================================

Place FastReport.rar in this folder:

  wwwroot/tools/FastReport.rar

It is served as a static file at:

  /tools/FastReport.rar

ERP Settings → Advanced Reporting → Transaction Reports has a
"Download FastReport tool" button that downloads this file so
users can edit .frx layouts locally, then upload them back.

Source copy is also kept under the Flutter project:
  erpflutter/tools/FastReport.rar

Copy this file to the server with the API publish/deploy.
